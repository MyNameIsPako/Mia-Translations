什么是 Mia？

Mia 是一款专注于 Fortnite 的 Discord 机器人，可让您管理账户、查看 库存、为服务器配置自动推送等。通过 Discord 中的简单 命令，您可以访问以下功能：

  • 查看您的 Fortnite 储物柜和外观物品
  • 通过 Discord 管理礼物和购买
  • 配置自动新闻和商店推送
  • 访问账户统计和资源
  • 使用 TaxiBot 进行自动任务
  • 访问面向开发者的 Mia API

服务的使用

Mia 通过 Discord 和我们的网站运行。要使用服务：

  • 您必须拥有有效的 Discord 账户
  • 您必须提供关联 Fortnite 账户所需的凭据（取决于所使用的 功能）
  • 您必须遵循机器人的指示，不得滥用服务
  • 您必须遵守这些条款以及 Discord 和 Epic Games 的政策
