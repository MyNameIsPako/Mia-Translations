Contas

Registo, segurança e dados que a Mia guarda da tua conta Epic.

Para registar a tua conta Fortnite na Mia, usa o comando /registrar no Discord. A Mia guia-te no resto dos passos.

Sim: a Mia não pede nem guarda a tua palavra-passe da Epic. O registo usa o fluxo oficial de autorização (device auth) e só armazena as credenciais técnicas necessárias (AccountID, DeviceID e Secret) numa base de dados privada. Não vendemos nem partilhamos os teus dados. Se quiseres deixar de usar a Mia, apaga-as com /borrar.

Para remover a tua conta da Mia, usa o comando /borrar. A Mia elimina as credenciais da tua conta (ou contas, conforme a opção), bem como o Auth gerado.

Existe um risco, embora seja muito raro. A Mia não usa comandos que ponham a tua conta em perigo. Os termos de serviço da Epic proíbem claramente apps de terceiros, mas em 8 anos de projeto nenhuma conta foi banida por usar um bot do Discord. Os nossos programadores e admins usam a Mia, tal como mais de 100.000 pessoas.

Para que a Mia funcione corretamente e possa aceder aos dados da tua conta Fortnite, gera-se um Auth composto pelo teu AccountID, DeviceID e Secret. Essas credenciais são usadas para gerar um accessToken, que depois permite interagir com a API do Fortnite. Estes dados são essenciais para que a Mia opere de forma adequada.

API

Chaves, limites e plano API Premium para programadores.

É uma API REST que expõe dados de Fortnite geridos pela Mia: loja de Battle Royale, recursos e alertas de Salvar o Mundo, estado de contas Epic e mais. A documentação completa está na página da API.

No Discord, usa o comando /api crear. A Mia gerará a tua chave privada e indicar-te-á como usá-la no header Authorization. Guarda-a num sítio seguro: não a partilhes nem a carregues para repositórios públicos.

A API gratuita tem limite de pedidos por minuto para uso pessoal ou testes. API Premium (5€/mês) aumenta o limite para 360 req/min e inclui imagens personalizadas da loja para BR e STW. Detalhes e comparação em Premium.

TaxiBots

Acesso a missões STW e bot lobbies de Battle Royale.

Os TaxiBots são contas automatizadas que te permitem aceder a missões de Salvar o Mundo (STW) com um nível de poder superior ao teu. Além disso, também os podes usar para entrar em botlobbies de Battle Royale (BR) e jogar com bots.

Para usar o sistema de TaxiBots:

  1. Junta-te ao servidor do Mia Lounge.
  2. Regista a tua conta na Mia com /registrar.
  3. Adiciona a tua conta aos táxis com /taxibot (activar).
  4. Adiciona algum bot.
  5. Convida um táxi.
  6. Põe a partida em não preencher e joga!
