アカウント

登録、セキュリティ、Epicアカウントに関してMiaが保存するデータ。

Fortnite アカウントを Mia に登録するには、Discord で /registrar コマンドを使います。残りは Mia が案内します。

はい：Mia は Epic のパスワードを要求も保存もしません。 登録は公式の認可フロー（device auth）を使い、必要な技術クレデンシャル （AccountID、DeviceID、Secret）だけをプライベートなデータベースに保存します。 データの販売や共有はありません。Mia の利用をやめたい場合は /borrar で削除してください。

Mia からアカウントを外すには /borrar コマンドを使います。選択したオプションに応じてアカウントの認証情報と生成された Auth が削除されます。

リスクはありますが、非常にまれです。Mia はアカウントを危険にさらすコマンドは使いません。Epic の利用規約は第三者アプリを明確に禁止していますが、このプロジェクトの 8 年間で Discord ボット利用による BAN はありません。開発者・管理者も 10 万人以上と同様に Mia を使っています。

Mia が正しく動作し Fortnite アカウントのデータにアクセスするため、 あなたの AccountID、DeviceID、 Secret から Auth が生成されます。これらのクレデンシャルで accessToken を作り、Fortnite API とやり取りします。 Mia の運用に不可欠なデータです。

いいえ。 Epic のパスワードを求めることはありません。デバイス認可フローのみを使い、Mia は device auth のクレデンシャルを保存します（メール/パスワードではありません）。

はい。無料プランには上限があります。Premium ならもっと多く管理できます。/cuentas または /cambiar で切り替えます。

Auth が無効になった場合（パスワード変更、Epic のセッション終了など）は /borrar のあと /registrar し直してください。 その目的で /refrescar は使わないでください： そのコマンドは Fortnite のミッション/プロフィールを更新するだけで、リンクは修復しません。

登録がまた失敗する場合は サポート でチケットを開いてください。

はい、公開機能（情報コマンド、Web など）はそのまま使えます。あなたの Epic アカウント（インベントリ、デイリー、ギフトなど）を管理するには /registrar が必要です。

/refrescar は Auth を更新したり Discord/Epic のセッションを「修理」したりしません。 Fortnite プロフィール（ミッション / クエスト）を Save the World と Battle Royale で更新します。

Mia 上のミッションやゲーム状態が古いときに使ってください。任意で initmm はマッチメイキング用プロフィールを初期化します。 Auth が無効なら /borrar のあと /registrar です。

Mia の Auth は無効になります。Mia でアカウントを /borrar し、/registrar で再リンクしてください。 /refrescar では直りません：ゲーム内ミッションの更新だけです。

Discord で /api crear コマンドを使います。Mia が プライベートキーを発行し、Authorization ヘッダーでの使い方を案内します。 安全な場所に保管し、共有したり公開リポジトリに上げたりしないでください。

無料APIには個人利用やテスト向けの毎分リクエスト上限があります。 API Premium（月5€）は上限を 360 req/min に上げ、BR/STWのカスタムショップ画像も含みます。詳細と比較は Premium へ。

TaxiBots

STWミッションとBattle Royaleボットロビーへのアクセス。

TaxiBots は、あなたより高いパワーレベルで Save the World（STW）ミッションに 入れる自動アカウントです。Battle Royale（BR）の botlobbies に入って ボットと遊ぶのにも使えます。

TaxiBots システムの使い方：

  1. Mia Lounge サーバーに参加します。

  4. ボットを追加します。
  5. タクシーを招待します。
  6. 試合を「埋まらない」にしてプレイ！
