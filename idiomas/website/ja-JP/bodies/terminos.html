Mia とは？

Mia は Fortnite に特化した Discord ボットで、アカウントの管理、インベントリの閲覧、 サーバー向け自動フィードの設定など、さまざまな機能を提供します。Discord 上の簡単な コマンドで、以下のような機能にアクセスできます：

  • Fortnite ロッカーおよびコスメティックの閲覧
  • Discord からのギフトおよび購入の管理
  • ニュースおよびショップの自動フィードの設定
  • アカウント統計およびリソースへのアクセス
  • 自動ミッション用 TaxiBot の利用
  • 開発者向け Mia API へのアクセス

サービスの利用

Mia は Discord および当社のウェブサイトを通じて動作します。サービスを利用するには：

  • 有効な Discord アカウントが必要です
  • Fortnite アカウントを連携するために必要な認証情報を提供する必要があります（利用する 機能により異なります）
  • ボットの指示に従い、サービスを悪用しないでください
  • 本規約および Discord および Epic Games のポリシーを遵守してください
